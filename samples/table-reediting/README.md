# 表の再編集の互換性サンプル

このフォルダーの `.adoc` は、生成処理から実行時に作らず、保存済みの入力としてテストに使います。SYUASで開き、表の中へカーソルを置いて「編集 → 表を再編集…」を試せます。試した変更を残す場合は別名保存してください。

| ファイル | 確認内容 |
| --- | --- |
| `basic.adoc` | 2×2、日本語・絵文字、空セル |
| `header.adoc` | タイトル、ヘッダー、2:1:1の列幅、縦結合・横結合 |
| `spans.adoc` | 2行×2列の複合結合、最終行の3列結合 |
| `full-span.adoc` | 3行×2列の全体結合、セル開始のない行の読み戻し |
| `entities.adoc` | パイプ・バックスラッシュの文字参照、太字、等幅、複数行・段落、HTML特殊文字 |
| `empty.adoc` | 2×2の全空セル、明示的なnoheader |

`unsupported/` は拒否動作を確認する入力です。header／noheader省略、CSV、セルスタイル、include、1行複数セルの5種類を含みます。再編集コマンドでは理由を表示し、ソースや元ファイルを変更しません。通常のソース編集は可能です。

改行はテスト側でLF／CRLFへ展開し、UTF-8のBOM有無と組み合わせて実ファイルへ保存します。期待するセルの座標・結合・内容は `tests/Syuas.Tests/TableCompatibilityFixtures.cs` に独立して定義しています。

全体結合ではHTML変換エンジンが空の行を省略します。デザイナーの論理行数とHTMLの `tr` 数は一致しない場合があります。詳細は [検証報告](../../docs/table-compatibility-validation.md) を参照してください。
