表の作成・再編集とUndo／Redoの使い方

この説明は「ヘルプ → 表の再編集の使い方」、または表デザイナー左下の「使い方」から開けます。説明を閉じると、編集中の表へ戻ります。

新しい表を作る

1. 「挿入 → 表…」またはツールバーの「表」を選びます。
2. 行数・列数を入力し「サイズを適用」を押します。初期値は3行×3列、最大100行×50列です。
3. セルへ文章を入力します。Enterでセル内に改行できます。表タイトル、ヘッダー、列幅は必要に応じて指定します。
4. クリックとShift＋クリックでセル範囲を選び、「セル結合」を押すと文章と結合範囲をまとめられます。
5. 右側のAsciiDocソースを確認し、「挿入」を押します。文書をファイルへ保存するには、その後Ctrl+Sを押します。

作成した表を再編集する

1. 表の中にカーソルを置きます。表の一部、または表全体を選択してもかまいません。
2. 「編集 → 表を再編集…」を選びます。右クリックメニューからも開けます。対象は現在のカーソル・選択範囲です。
3. 表デザイナーでセルの内容、行列、結合、タイトル、ヘッダー、列幅を修正します。
4. 右側のAsciiDocソースを確認し、「適用」を押します。
5. 文書に反映した内容を保存するにはCtrl+Sを押します。HTMLの表示は「表示 → HTMLプレビュー」で確認できます。

元に戻す・やり直し

・「元に戻す」またはCtrl+Zで、直前の編集を取り消します。「やり直し」またはCtrl+Y／Ctrl+Shift+Zで戻せます。入力欄の右クリックからも操作できます。
・対象はセル本文、タイトル、列幅、ヘッダー設定、結合・結合解除、行列の追加・削除、サイズ変更です。セル入力中でも表全体の編集を操作順に戻します。ボタンにマウスを置くと、次に戻す操作名を確認できます。
・同じセル・タイトル・列幅への連続入力はまとめて1回で戻します。別の欄への移動、マウスや方向キー等のカーソル操作、全選択、切り取り／貼り付け、IMEの開始・確定で区切ります。時間が経っただけでは区切りません。
・行数・列数の入力から「サイズを適用」までは、途中に別の内容変更がなければ1回で戻します。未適用の数値や不正な列幅も取り消せます。不正な値をRedoで復元した場合は、直すまで挿入／適用できません。
・Undo／Redo後には入力欄と文字の選択位置、表の選択範囲も戻ります。選択・カーソル移動だけでは履歴は増えません。

例：結合してから行を削除した場合

1. 2つのセルに「項目」「説明」と入力し、Shift＋クリックで2セルを選んで結合します。
2. 「行削除」を押した後、Ctrl+Zを1回押すと、削除した行と内容が戻ります。
3. もう1回Ctrl+Zを押すと結合前に戻り、「項目」「説明」が元の別々のセルに復元されます。
4. Ctrl+Yで結合を、もう1回Ctrl+Yで行削除をやり直せます。

「結合解除」は文章を左上セルに残してセルを分割する操作です。「結合をUndo」は、結合前の各セルへ元の文章を戻す操作です。

やり直しが使えないとき

・Undoした後に別の編集を行うと、その先のRedo履歴は破棄されます。選択だけの変更では破棄されません。
・まだ編集していない、取り消せる履歴を使い切った、またはIME変換中の場合は、該当するボタンが無効になります。
・履歴はこのダイアログを開いている間だけ保持します。閉じて再度開くと空になります。通常は100操作・推定32MiBを上限とし、超えた分は古い操作から失われます。直近の1操作は大きくても保持します。
・履歴の上限を超えた後に修正全体を破棄したい場合も、「キャンセル」で文書を変更せずに戻れます。

日本語IMEで入力するとき

変換中はUndo／Redo・表の構造変更・ヘッダー変更・挿入／適用・キャンセル・使い方ボタンを無効にします。Escapeは変換の取り消しに使えます。確定・変換の取り消し後に表の操作を続けてください。変換を取り消して元の内容へ戻った場合は、その変換の履歴は増えません。

取り消しと保存

・「適用」は元の表だけを置き換えます。前後の本文や独立したAnchor・コメントは保持します。
・文書へ適用した変更はCtrl+Z 1回で取り消せます。Ctrl+Yでやり直せます。
・「挿入」「適用」は編集中の文書への反映です。ファイルへの保存は、その後Ctrl+Sで行います。
・「キャンセル」、変換中以外のEscape、右上の閉じるボタンでは文書と文書側のUndo／Redo履歴を変更しません。
・再編集で全変更をUndoして元の内容へ戻してから適用した場合も、文書の未保存状態やUndo／Redo履歴を変えません。
・デザイナーを開いている間は、文書の切り替え・保存を行えません。先に適用またはキャンセルしてください。

再編集できる表

現在のSYUASが生成する形式の表を対象としています。同じ形式を維持して直接ソースを編集した表も扱えます。
タイトル、明示的なヘッダー有無、列幅、空セル、複数行の本文、横結合・縦結合・複合結合に対応します。上限は100行×50列です。
列指定は cols="N*" または正の整数の列幅リスト、ヘッダー指定は options="header" または options="noheader" が必要です。行末はLFまたはCRLFに統一してください。

再編集できない例

・古い出力などでheader／noheader指定が省略されている表。
・CSV、追加属性、配置やセルスタイル、1行に複数のセルが書かれた表。
・includeや条件分岐を含む表、入れ子の表。
・コード例、引用・例示などのブロック、条件分岐、リスト継続の中にある表。
・複数の表や周囲の本文にまたがる選択、区切りが欠けている表。

対応外でも通常のソース編集はできます。自動変換・自動修復は行いません。
「表を再編集できませんでした」と表示されたら、案内された行・列と理由を確認してください。属性を足すだけで任意の表が対応形式になるわけではありません。表示が変わる修正をする場合は、元のソースを残してHTMLプレビューでも確認してください。

セル内の文字の扱い

セルはAsciiDocソースとして編集します。デザイナー右側は生成するソースの表示です。*太字*などの表示結果は、適用後に文書の「表示 → HTMLプレビュー」で確認できます。
パイプは &#124;、パイプ直前のバックスラッシュは &#92; と表示されることがあります。文字参照はそのまま保持し、HTMLの文字へ自動で戻しません。
空白や改行も保持しますが、HTMLではAsciiDocの規則に従って段落・空白として表示されます。デザイナーの行の高さとHTML上の行の高さは同じとは限りません。
例えば表全体を3行×2列で結合すると、デザイナーでは3行分を保持しますが、同梱のHTML変換エンジンは1つの行とrowspan="3"のセルを出力します。空の行が3行分の高さとして表示されるわけではありません。

適用できない場合

入力が対応形式から外れると、画面下部へ理由を表示します。入力内容は保持されるので修正して再度適用できます。
適用に失敗してもデザイナーの履歴は残ります。直前の編集をUndoして修正するか、Redoで戻して内容を確認できます。失敗した「適用」自体は履歴を増やしません。
デザイナーを開いた後に元の文書が変わっていた場合は、古い内容による置き換えを防ぐため適用を中止します。必要な内容を右側のソースからコピーして退避し、キャンセルして表を開き直してください。

自動復元・外部変更との関係

デザイナー内で未適用の変更は復元用コピーに入りません。自動退避の対象は文書へ適用済みの内容です。適用後でも次の退避が完了する前の強制終了では、最新の変更を復元できないことがあります。確実に残したい場合はCtrl+Sで保存してください。
文書側のUndoで保存済みの状態に戻ると、復元用コピーは整理されます。Redoで未保存の変更を戻すと、その内容が次の自動退避の対象になります。
復元した文書内の表も再編集できます。復元した内容は未保存として扱います。
復元後もデザイナーの履歴は空から始まります。前回のデザイナーや文書のUndo履歴は復元しません。
デザイナーを開いている間に元ファイルが外部で変更されても、ローカルの編集を自動で捨てたり上書きしたりしません。デザイナーを閉じて通知を確認し、比較・名前を付けて保存・バックアップ付き上書きなどを選んでください。通知を閉じても保存前の競合チェックは有効です。
デザイナーや文書でUndo／Redoを行っても、外部変更を確認済みとして扱うことはありません。
詳しい対処は「ヘルプ → 自動復元と外部変更の使い方」で確認できます。
