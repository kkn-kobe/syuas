# データ保存設定

「ツール(T) → 設定…」から変更します。OKで設定を保存し、開いている全タブにも適用します。キャンセルでは変更しません。

| 設定 | 動作 |
| --- | --- |
| 復元用コピーを自動作成する：オン（初期値） | 未保存の編集内容を文書フォルダー外へ退避し、異常終了後の復元を可能にします。 |
| 復元用コピーを自動作成する：オフ | 新しい退避と復元操作を停止します。既存のコピーは保持します。 |
| HTMLプレビュー：保持する（初期値） | `%LOCALAPPDATA%\SYUAS\WebView2` を利用します。 |
| HTMLプレビュー：終了時に削除する | 起動・設定切り替えごとに専用領域を作成し、プレビュー停止時に今回分を削除します。 |
| HTMLプレビュー：作成しない | HTMLプレビューを無効にし、ブラウザーを初期化しません。 |

復元用コピーを作らずプレビューを利用する場合は、自動復元をオフにし、プレビューを「終了時に削除する」にします。未保存の編集内容は異常終了後に復元できなくなります。通常保存、Undo／Redo、外部変更の検出は引き続き利用できます。

## 終了時削除の範囲

一時的なプレビュー用データは `%LOCALAPPDATA%\SYUAS\PreviewSessions\<ID>\Data` に保存します。復元用コピーとは別の領域です。正常終了時には未保存文書の確認を終えてからプレビューを停止し、WebView2のプロセス終了を待ってDataフォルダーを削除します。確認で終了をキャンセルした場合は削除せず、編集を続けられます。本文を含まない管理用ファイルは次回起動時に整理します。

強制終了や電源断では削除できない場合があります。次回起動時に、終了時削除に指定された過去の領域だけを掃除します。他の起動中のSYUASが使用中の領域は排他ロックで除外します。削除失敗や終了待ちのタイムアウトは通知し、残ったデータは次回起動時に再試行します。これは通常のファイル削除であり、消去済み領域の復元不能化を保証するものではありません。

以前の「保持する」で保存されたWebView2データ、以前の復元用コピー、最近使用したファイルの履歴、ユーザーが保存した文書、文書と同じフォルダーのバックアップは、この設定の変更では削除しません。設定を切り替える前に作成された内容が残り得る点に注意してください。

## WebView2のSmartScreenとクラッシュ報告

SYUASのHTMLプレビューでは、Microsoft Defender SmartScreenを明示的に無効化し、WebView2のクラッシュ情報のMicrosoftへの自動送信も停止しています。「保持する」「終了時に削除する」のどちらでも適用します。

初期化時に `CoreWebView2EnvironmentOptions.IsCustomCrashReportingEnabled = true` を指定して自動送信を停止し、最初のページ表示より前に `CoreWebView2Settings.IsReputationCheckingRequired = false` を設定します。SYUAS独自のクラッシュ情報送信処理は設けていません。

クラッシュダンプのローカル生成や、WebView2のその他の診断データ収集をすべて停止する設定ではありません。任意の診断データはWindowsの診断設定に従い、必須の診断データは別に収集されます。詳細はMicrosoftの[WebView2のデータとプライバシー](https://learn.microsoft.com/ja-jp/microsoft-edge/webview2/concepts/data-privacy)を参照してください。

変更前のSYUASが起動中の場合は、すべて終了してから更新版を起動してください。同じユーザーデータフォルダーを使うWebView2間ではSmartScreenの設定が共有されます。

## 設定の保存・共有

設定値だけを `%LOCALAPPDATA%\SYUAS\settings.json` に保存します。同じユーザーで起動しているSYUASは約1秒ごとに変更を確認します。別ウィンドウでダイアログや文書操作が進行中の場合、反映はその操作終了後になります。すべてのウィンドウに反映されるまでを含む、瞬時の一括停止を保証する機能ではありません。

初回の文書オープンより先に設定したい場合は、引数なしで起動して設定します。配布時に次の設定ファイルを配置しておくこともできます。

```json
{
  "RecoveryEnabled": false,
  "PreviewData": "DeleteOnExit"
}
```

`PreviewData` は `Keep`、`DeleteOnExit`、`Disabled` のいずれかです。設定が破損している、または読み取れない場合は自動復元とプレビューを停止して通知します。設定ファイルがない初回起動では従来どおり有効です。SYUAS自身のデータ保存を制御する設定であり、OSのページファイルや外部ソフトウェアによる保存は対象外です。

## 検証

`SettingsTests` で設定の保存・破損検出、使用中セッションの除外、今回分だけの削除、削除失敗と再試行を確認します。`RecoveryServiceTests` は書き込み中の停止と、その後の新規退避抑止を確認します。`WindowTests` は設定画面のバインディング、プレビュー無効時のブラウザー未初期化、復元の再有効化を確認します。

実際のWebView2による表示と終了時削除は、通常のテストとは別に次の指定で実行できます。独立したテスト用プロファイルを使用します。

```powershell
$env:SYUAS_WEBVIEW_SMOKE = Join-Path (Get-Location) 'artifacts/settings-validation/webview'
dotnet test tests/Syuas.Tests/Syuas.Tests.csproj --filter FullyQualifiedName~WindowTests
```

2026-10-02に、WebView2を使用したHTML・画像・includeの表示、タブ切り替え後の表示、ブラウザー解放後の専用Dataフォルダー削除が成功しました。ブラウザー子プロセスの起動を制限した環境では初期化が完了しない場合があるため、この追加検証はWebView2を起動できるWindows環境で実行してください。
